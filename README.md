# Integrity Preservation Theory (IPT) Reference Lab

Integrity Preservation Theory (IPT) is a constitutional framework for preservation-oriented integrity evaluation in bounded systems.

This repository provides the normative doctrine, formal specifications, executable reference implementation, validation corpus, evidence artifacts, metrics, and release materials supporting the Integrity Preservation Theory publication.

---

# Constitutional Object

IPT evaluates whether a bounded system remains sufficiently preserved to be treated as the same evaluative object.

The constitutional object of IPT is preservation-oriented integrity evaluation.

---

# Repository Purpose

This repository demonstrates a complete reference implementation of Integrity Preservation Theory.

It is intended to provide:

• Constitutional doctrine

• Formal specification

• Reference implementation

• 100-case validation corpus

• Structured evidence artifacts

• Integrity metrics

• Replay capability

• Release documentation

The repository is designed to show reproducible preservation-oriented integrity evaluation rather than domain-specific deployment.
