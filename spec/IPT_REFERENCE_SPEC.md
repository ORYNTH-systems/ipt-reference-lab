# Integrity Preservation Theory (IPT) Reference Specification

## Specification v1.0

This document defines the normative technical specification governing all conforming Integrity Preservation Theory (IPT) implementations.

The specification is subordinate to the constitutional doctrine while governing every executable implementation contained within this repository.

---

# 1. Constitutional Objective

Every IPT implementation shall evaluate whether a bounded system remains sufficiently preserved to be treated as the same evaluative object.

No implementation may substitute another constitutional objective.

# 7. Evidence Constraints

Integrity determination shall never exceed available evidence.

Evidence insufficiency constrains every downstream stage.

Evidence uncertainty shall remain explicitly represented.

---

Maintain constitutional separation between evidence and interpretation.
